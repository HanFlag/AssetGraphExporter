# 커맨드렛과 상주 서버

> 에디터 창 없이 엔진을 띄워 일하는 방식. 1단계 내보내기와 2단계 상주 서버가 이것으로 동작한다.

## 커맨드렛
- `UnrealEditor-Cmd.exe <프로젝트>.uproject -run=<이름>`. 에디터 엔진을 만들고 엔진 초기화(PostEngineInit)까지 거친 뒤 `Main()`을 실행하고 끝난다.
- `-PLUGIN=<.uplugin 경로>`: 프로젝트 밖의 플러그인을 이 프로세스에서만 불러온다. 프로젝트 파일을 바꾸지 않고 테스트할 수 있는 이유. 이 방식으로 불러온 플러그인은 에디터 Plugins 창에 안 보인다.
- 커맨드렛은 에셋 목록을 백그라운드로 스캔하지 않는다 → `SearchAllAssets(true)`를 직접 부른다.
- 텍스트 언어를 영어로 고정한다(`-culture=`를 주면 그것을 따름). 노드 제목 등이 PC 언어에 따라 달라지는 것을 막기 위해.
- 측정(2026-10-23, 에셋 3개): 엔진 시작 8.6~12.2초, 스캔 0.26초, 로드·내보내기 약 0.5초. 비용 거의 전부가 엔진 시작.

## 상주 서버 (`AssetGraphServe`, `Serve.bat`)
- 커맨드렛이 끝나지 않고 MCP 서버를 켜 둔 채 기다린다. 루프에서 하는 일: 게임 스레드 작업 처리, `FTSTicker`(HTTP·MCP 서버), 스레드 매니저.
- 멈추는 조건: `age_shutdown`, Ctrl+C, 유휴 시간(기본 30분), 에디터가 켜졌을 때(같은 포트를 에디터에 넘김). 에디터가 이미 켜져 있으면 `Serve.bat`이 엔진을 띄우기 전에 거절한다.
- 디스크 저장본 기준. 요청받은 에셋의 파일이 바뀌었으면 `UPackageTools::ReloadPackages`로 다시 읽는다(실제 시험은 아직).
- 켜져 있는 동안 프로젝트·플러그인 DLL을 잡고 있어서 **C++ 빌드 전에는 꺼야 한다.**
- 측정(2026-10-24): 재부팅 뒤 첫 준비 62초(Zen 저장소 서버 8.8초 + 셰이더 타입 준비 17초 포함, 다음 실행에서는 둘 다 1초 안팎), 이후 호출 4~460ms, 종료 요청 후 3.4초.

## 에디터 모드
- `Editor.bat`이 같은 `-PLUGIN=` 인자로 에디터를 연다. 에디터 안의 MCP 서버에 같은 도구가 올라가고, 저장 안 한 변경까지 보인다.
