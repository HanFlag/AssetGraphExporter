# 기획서

> 마지막 갱신: 2026-10-26

## 1. 목적
- 여러 Unreal 프로젝트에서 재사용할 에디터 플러그인. 에디터 창 없이 에셋 구조(BP, AnimBP, StateTree, Niagara 등)를 JSON으로 꺼내, AI 코딩 도구(Claude Code)가 에디터를 끈 상태에서도 바이너리 에셋의 내용을 알게 한다.
- 2단계부터는 MCP 도구로 바로 물어볼 수 있게 한다. 목표: 엔진 내장 Unreal MCP보다 넓게(에디터 꺼짐, AnimBP, Simulation Stage 등) 다루기.
- 다음 새 게임 프로젝트에 이 플러그인을 처음부터 적용할 계획.

## 2. 원칙
- `.uasset`을 직접 해석하지 않는다. 엔진 API로 에셋을 로드한다(커맨드렛 / 에디터 안).
- 범용성: 프로젝트 이름·에셋 경로·게임 클래스가 코드에 없다. 플러그인 폴더만 복사하면 다른 프로젝트에서 동작한다.
- 기본은 리플렉션 범용 내보내기. 리플렉션으로 안 되는 것만 전용 처리기(그래프, AnimGraph 바인딩, StateTree, Niagara 스택).
- 읽기 전용. 에셋을 저장하는 코드는 없다(수정 기능은 3단계 후보, 별도 안전장치 필요).
- 외부 상용 도구는 공개된 기능 설명만 "어떤 기능이 쓸모 있나" 참고. 제품·소스·문서 문장은 보지 않고, 구현은 엔진 소스와 공식 API만 근거로 한다. 이름과 문서도 새로 쓴다.
- 엔진 API와 동작은 추측하지 않고 엔진 소스(5.8.4)로 확인한다.
- 같은 에셋은 매번 바이트 단위로 같은 JSON이 나와야 한다 → [[같은 에셋은 같은 JSON]].

## 3. 구조
- 저장소 하나에 플러그인 두 개.
  - `AssetGraphExporter`: 범용 + Blueprint/AnimBP + 커맨드렛 `AssetGraphExport` + 요약(`AGE::Summary`) + JSON 선택(`AGE::JsonQuery`). 선택 모듈 `AssetGraphExporterStateTree`, `AssetGraphExporterNiagara`(각 플러그인에 Optional 의존, 에디터 전용).
  - `AssetGraphExporterMcp`: 엔진 내장 Unreal MCP 서버에 `age_*` 도구를 직접 등록 + 에디터 없이 서버를 띄우는 커맨드렛 `AssetGraphServe` + 활동 창 페이지. Unreal MCP가 Experimental이라 따로 둠.
- 실행 경로: Claude Code → `127.0.0.1:8000/mcp` 하나. 에디터가 켜져 있으면 에디터 안 서버(저장 안 한 변경까지), 꺼져 있으면 `Serve.bat` 상주 서버(디스크 저장본) → [[Unreal MCP 내장 서버]], [[커맨드렛과 상주 서버]].
- 테스트 프로젝트(MomentTrigger)는 `-PLUGIN=` 실행 인자로 플러그인을 불러와서, 그 프로젝트 파일을 하나도 바꾸지 않는다.

## 6. 작업 방식
- **분담**: 로컬 세션 하나가 설계·코드 작성부터 빌드·테스트·커밋까지 한다. 세션을 나눌 때는 같은 PC의 로컬 세션끼리 메시지로 주고받는다.
- **확인**: "완료"는 빌드 로그·결과 파일을 직접 읽고 확인한 뒤에만. 새 엔진 타입은 정의된 헤더를 직접 include한다.
- **수정 전 확인**: 고치기 전에 매번 사용자에게 묻는다. 범위를 넓힐 때도 묻는다.
- **테스트 프로젝트 규칙**: MomentTrigger의 브랜치를 만들거나 바꾸지 않는다. `Source/`, `Content/`, `Config/`, `Docs/`, `DevNotes/`를 건드리지 않는다. 테스트는 읽기만 한다.
- **커밋**: 메시지 끝에 Co-Authored-By 줄만 넣는다(Claude-Session 줄 없음). push는 사용자가 정할 때만.
- **설명**: 한국어, 쉬운 말. 어려운 용어는 짧게 풀어서.
