# 같은 에셋은 같은 JSON

> 에셋이 바뀌지 않았으면 내보낸 JSON이 바이트 단위로 같아야 한다. 2단계의 캐시·증분 내보내기와 리비전 diff가 이것을 전제로 한다.

## 지키는 방법
- 키 순서 고정, GUID는 모두 `8-4-4-4-12` 형식.
- 기본값과 다른 값만 쓴다(diff 모드). 비교 기준: 객체는 아키타입(CDO/템플릿), 구조체는 새로 만든 같은 타입, BP의 Class Defaults는 부모 CDO.
- 텍스트 언어 영어 고정(커맨드렛).

## 불러올 때마다 바뀌는 값 (발견하면 여기에 추가)
| 값 | 어디 | 처리 | 날짜 |
|---|---|---|---|
| 숨김 핀의 핀 id | AnimBP 전환 규칙의 비교 노드 `ErrorTolerance` 핀 등(저장되지 않고 로드 때 새 GUID) | 연결이 있거나 분할 핀의 부모일 때만 id를 쓴다 | [[2026-10-23]] |
| `CachedChangeId` | 나이아가라 함수 호출 노드("컴파일할 때마다 바뀜") | 그래프 노드 속성에서 뺀다 | [[2026-10-26]] |
| 자동 배치된 비활성 노드의 안내 코멘트 | 노드가 처음 배치된 PC의 언어로 저장됨(바뀌지는 않지만 의미 없는 글) | `"ghost": true`로 대신 표시 | [[2026-10-23]] |

## 확인 방법
- 같은 에셋을 두 번 내보내고 `fc /b`로 비교. 에디터를 켠 상태와 끈 상태 모두.
