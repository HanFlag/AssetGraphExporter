## 기록 규칙
- **이 볼트(`Docs/`)는 git에 올라간다.** 그래서 대화 원문 인용, 개인 정보, 개인 PC 경로(사용자 폴더)는 적지 않는다. 결정은 한 줄 요약과 이유로 적는다.
- 의미 있는 결정이나 진행이 있던 날은 `log/`에 날짜 파일을 새로 만든다. 형식은 [[진행 기록]] 템플릿.
- 지난 날짜 파일은 고치지 않는다. 틀린 게 있으면 새 날짜 파일에 "정정"으로 적는다.
- "사용자가 확인한 것"과 "제안·안내만 한 것"을 구분해서 적는다.
- 끝난 일은 [[할일]]에서 체크하고, 결정이 나면 그날 log에 결정사항으로 남긴다.
- 엔진 구조처럼 계속 참고할 사실은 log가 아니라 `개념/` 문서에 적는다.
- 기록 담당: PC의 Claude Code 세션은 "기록해" 또는 `/clear` 전에 `memory-recorder` 에이전트가 쓴다(`CLAUDE.md`).
