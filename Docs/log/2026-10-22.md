# 2026-10-22

## 결정사항
- **별도 작업 폴더·자체 git 저장소**로 만든다(사용자 결정). 원래 계획은 MomentTrigger의 `Plugins/` 안이었지만, 독립 도구라 따로 두는 게 범용성 확인에도 맞음. 테스트만 MomentTrigger에서.
- 이름 `AssetGraphExporter`, 클래스 접두사 `AGE`. 차별점이 그래프라서 그대로 씀.
- 작업 방식: 이번에는 Claude가 코드를 전부 작성(사용자 결정).
- 외부 상용 도구(발표에서 본 것)는 공개 기능 설명만 아이디어로 참고, 구현은 엔진 소스·공식 API만(사용자 규칙).
- **테스트 프로젝트를 하나도 안 바꾸는 방법**: 엔진 실행 인자 `-PLUGIN=<.uplugin>`(엔진 `PluginManager.cpp`로 확인). 그래서 MomentTrigger의 `.gitignore`·`.uproject` 수정 계획은 필요 없어짐.
- StateTree 처리기는 별도 모듈 + Optional 의존. 확인 결과 Optional은 "플러그인 파일이 없으면 무시"일 뿐이라, 있으면 StateTree가 함께 켜짐 → `TargetAllowList: Editor`로 게임 빌드 영향 차단.
- 5.8에서 AnimGraph 바인딩은 노드의 `Binding` 하위 객체(`PropertyBindings`)에 있음. 엔진 내부 전용 타입이라 리플렉션으로 이름을 찾아 읽기로 함.

## 진행상황
- 엔진 소스로 계획의 불확실한 부분 확인(위 결정들).
- 1단계 코드 작성: 범용 리플렉션 writer, Blueprint/AnimBP 처리기, 커맨드렛 `AssetGraphExport`, StateTree 모듈, README, 배치 파일(`Setup`/`Build`/`Export`/`LocalConfig`). 32개 파일, **컴파일 전**.
- 질문 답변(안내만): `-PLUGIN=` 방식은 에디터 Plugins 창에 안 보임. 프로젝트 `Plugins/`에 복사하거나 환경 변수 `UE_ADDITIONAL_PLUGIN_PATHS`를 쓰면 보임. Plugins 창에서 체크를 바꾸면 `.uproject`가 수정되니 테스트 중에는 건드리지 않기.
