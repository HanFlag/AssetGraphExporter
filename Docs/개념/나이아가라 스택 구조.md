# 나이아가라 스택 구조

> 에디터의 나이아가라 스택(이미터 → 스크립트 → 모듈 → 입력값)이 에셋 안에 어떻게 저장되는지. `AssetGraphExporterNiagara`가 이 규칙대로 읽는다. UE 5.8.4 소스 기준.

## 어디에 있나
- 시스템: `UNiagaraSystem` — 이미터 핸들 목록, 시스템 스폰/업데이트 스크립트, 사용자 파라미터(`GetExposedParameters()`).
- 이미터: 핸들(`FNiagaraEmitterHandle`) → 버전별 데이터 `FVersionedNiagaraEmitterData`. 경량(Stateless) 이미터는 그래프가 없다.
- 이미터의 모든 스크립트는 **그래프 하나**(`GraphSource` → `UNiagaraScriptSource::NodeGraph`)에 들어 있다. 사용처마다 출력 노드(`UNiagaraNodeOutput`)가 하나씩: 이미터·파티클 스폰/업데이트, 이벤트 핸들러(사용처 ID), **Simulation Stage(스테이지마다 사용처 ID)**.

## 모듈 순서
- 출력 노드의 파라미터 맵 입력 핀에서 거꾸로 따라가면 스택이 나온다. 체인 위의 함수 호출 노드(`UNiagaraNodeFunctionCall`)가 모듈.
- 모듈 앞에는 오버라이드 노드(`UNiagaraNodeParameterMapSet`, 엔진 내부 클래스)가 있을 수 있다. 동적 입력이 자기 입력을 가지면, 이전 모듈과 그 사이에 공유 오버라이드 노드가 하나 더 끼어든다(엔진 `GetOrCreateStackFunctionOverrideNode`).
- 모듈이 꺼졌는지는 노드의 활성 상태(`IsNodeEnabled`).

## 입력값은 두 곳
- **오버라이드 핀**: 오버라이드 노드의 `<모듈 이름>.<입력 이름>` 핀. 연결된 것에 따라
  - 파라미터 맵 읽기 노드 → 다른 파라미터에 연결(예: `User.WorldSpaceSize`)
  - 함수 호출 노드 → 동적 입력(같은 규칙으로 중첩)
  - 입력 노드 → 데이터 인터페이스 또는 오브젝트 에셋
  - 연결 없음 → 핀의 기본값 문자열
- **RapidIterationParameters**: 상수로 넣은 값. 그 스택의 스크립트(이미터 스폰이면 이미터 스폰 스크립트, Simulation Stage면 스테이지 스크립트)의 파라미터 저장소에 `Constants.<이미터 고유 이름>.<모듈 이름>.<입력>`으로 들어 있다. 이름은 엔진 `FNiagaraUtilities::CreateRapidIterationConstantName`(공개)로 만든다. 사용처는 출력 노드의 것을 쓴다.
- 둘 다 없으면 모듈 기본값. 정적 스위치는 함수 호출 노드 자신의 핀.
- 큰 좌표(LWC) 멤버가 있는 구조체는 저장소에 float 배치로 들어 있어, 변수의 `StructConverter`로 되돌려 읽어야 한다.
- enum은 대부분 사용자 정의 enum이라 값 이름이 `NewEnumerator0..`. 에디터에 보이는 이름은 `GetDisplayNameTextByIndex`.

## 엔진 API 상태 (5.8)
- 내장 MCP의 나이아가라 도구(`UNiagaraExternalEditUtilities`)는 값을 읽을 때마다 스택 화면 모델(`FNiagaraSystemViewModel`)을 만들고, 스택을 4개(이미터·파티클 스폰/업데이트)만 찾는다. Simulation Stage 필드가 없다. 유체 시스템에서는 그 4개도 "Script not found"로 실패했다.
- 가벼운 공개 API `UE::Niagara::FSystemAdapter`: 모듈 순서·입력 이름은 주지만 입력값 읽기 함수가 모두 실패를 돌려주는 미완성 코드.
- `FNiagaraStackGraphUtilities`의 모듈 순서·오버라이드 노드 함수는 외부 공개가 아니다. 입력 목록 함수 `GetStackFunctionInputs`(숨겨진 입력 집합 포함)와 `GetStackFunctionStaticSwitchPins`는 공개.
- 함수 호출 노드의 `CachedChangeId`는 "스크립트를 컴파일할 때마다 바뀌는" 값이라, 같은 에셋을 다시 불러오면 달라진다 → [[같은 에셋은 같은 JSON]].
